# 1주차

## 1. 운영체제가 무엇인지 설명하시오.
- 컴퓨터의 하드웨어 자원을 관리하고 프로그램들이 실행될 수 있는 환경을 제공해주는 소프트웨어
- 대표적으로 윈도우, 맥OS, 리눅스 등이 있다.

## 2. 프로세스와 스레드의 차이를 설명하시오.
- 프로세스는 실행 중인 프로그램을 말하고 각각 독립된 메모리 공간을 가진다.
- 스레드는 프로세스 안에서 실제로 일을 처리하는 실행 단위이고 프로세스의 메모리를 공유해서 사용한다.
- 스레드끼리 데이터를 주고받기는 쉽지만 하나의 스레드가 잘못되면 다른 스레드 또한 영향을 받는다.
- 프로세스는 독립적이라 안정적이지만 통신하는데 비용이 더 든다.

## 3. 뮤텍스와 세마포어를 설명하시오.
- 여러 스레드가 공유 자원에 동시에 접근하지 못하도록 막는 도구
- 뮤텍스는 자원에 하나의 스레드만 접근할 수 있게 하는 잠금장치, 잠근 쪽만 풀 수 있는 소유권 개념
- 세마포어는 카운트를 가지고 있어 동시에 접근 가능한 개수를 지정할 수 있다

## 4. 동기와 비동기의 차이에 대해 설명하시오.
- 동기는 작업을 요청하면 결과가 나올 때까지 기다렸다가 다음 작업을 하는 방식
- 비동기는 작업을 요청하고 결과를 기다리지 않고 다른 일을 하다가 작업이 끝나면 결과를 받는 방식
- 동기는 순서대로 작업이 진행되니까 흐름이 단순하다는 장점이 있지만 오래 걸리는 작업동안 아무것도 못한다.
- 비동기는 자원을 효율적으로 사용할 수 있지만 순서를 보장할 수 없고 흐름 추적이 힘들다.

## 5. blocking과 non-blocking에 대해 설명하시오.
- blocking은 어떤 작업을 호출했을 때 그 작업이 끝날 때 까지 제어권으로 넘겨주지 않는 것
- non-blocking은 작업이 끝나지 않아도 제어권을 돌려줘서 호출 한 쪽이 작업을 할 수 있게 함
- 동기/비동기와 다른 점은 제어권에 있다. 블로킹은 작업이 끝날 때 까지 기다리는 것이고 논블로킹은 다음 작업을 기다리지 않고 하는것이다.

## 6. deadlock에 대해 설명하시오.(발생 조건, 해결 방법 포함)
- deadlock은 두 개 이상의 프로세스가 서로 가진 자원을 기다리면서 무한히 멈춰있는 상태를 말한다.
- 발생 조건 4가지가 모두 만족해야 데드락이 발생한다.
- 1. 상호 배제: 자원을 한 번에 하나만 쓸 수 있어야 한다.
  2. 점유와 대기: 자원을 가진 채로 다른 자원을 기다리는 상태
  3. 비선점: 다른 프로세스 자원을 강제로 뺏을 수 없다.
  4. 순환 대기: 프로세스들이 원형으로 서로의 자원을 기다리는 상태
- 해결 방법으로는 위 조건 중 하나를 풀어서 발생하지 않도록 하거나, 자원을 할당할 때 미리 검사하는 방식, 데드락이 생기면 탐지해서 복구하는 방법이 있다.

## 7. 컨텍스트 스위칭에 대해 설명하시오.
- CPU가 실행하던 프로세스를 멈추고 다른 것을 실행할 때 기존 작업 상태를 저장하고 새 작업 상태를 불러오는 과정
- 여기서 상태는 레지스터 값이나 프로그램 카운터와 같은 정보인데 PCB에 저장해두는 방식
- 너무 자주 일어나면 오버헤드가 생긴다.

## 8. 가상 메모리와 페이징에 대해 설명하시오.
- 가상 메모리는 실제 메모리보다 더 큰 메모리를 쓸 수 있는 것처럼 보이는 기술
- 필요한 부분만 물리 메모리에 올리고 나머지는 디스크에 두고 필요할 때 가져오는 방식
- 페이징은 가상 메모리를 구현하는 방법
- 메모리를 페이지라는 고정된 크기로 잘라서 관리한다.
- 가상 메모리의 페이지와 물리 메모리의 프레임을 테이블로 매핑해서 실제로 메모리가 흩어져 있어도 프로그램을 실행할 수 있게함

## 9. 선점형 스케줄링과 비선점형 스케줄링의 차이에 대해 설명하시오.
- 선점형 스케줄링은 다른 프로세스가 CPU를 쓰고있어도 운영체제가 필요하면 강제로 뺏어서 다른 프로세스에게 넘겨주는 방식
- 비선점형 스케줄링은 CPU를 사용하고 프로세스가 스스로 끝나거나 I/O와 같은 이유가 넘겨줄 때 까지 사용하는 방식
- 선점형 예시로는 라운드 로빈이 있고, 비선점형으로는 FCFS로 먼저 온 프로세스가 끝날 때까지 계속 사용하는 방식이 있다.
