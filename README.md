# 🎤 Interview Study

> **운영체제와 네트워크의 주요 면접 질문을 정리하고 실제 면접 형식으로 연습하는 스터디입니다.**

---

## 🌳 스터디 진행 방식

- **인터뷰 스터디**: 매주 금요일 진행 (※ 일정은 상황에 따라 변경 가능)
- **질문 업로드 마감**: 매주 화요일
- **과제**
  - 스터디원마다 자주 출제되는 면접 질문을 준비합니다.
  - **운영체제 질문 3개, 네트워크 질문 3개**를 업로드합니다.
  - 질문별로 핵심 답변과 예상 꼬리 질문을 작성합니다.
- **진행 방식**: 서로 면접관과 지원자 역할을 맡아 질문하고 답변한 후 피드백합니다.
